# DATA PATH v4.0.3

DATA PATH 90日データアナリスト学習の学習管理アプリ。

## 更新方法

このフォルダ内のファイルを、GitHubリポジトリ `taijukubo-jpg/data-path-90` のルートへ同名で上書きする。

特に重要な修正ファイル：

- `glossary-index.js`
- `glossary-ui.js`

安全のため、全ファイルをまとめて上書きして問題ない。

## 反映後の確認

1. GitHub Pagesの反映を待つ
2. ブラウザで `Ctrl + F5` を実行
3. 用語一覧が表示されることを確認
4. 関連用語をクリックし、対象カードへ移動することを確認
5. 検索欄が空のままであることを確認

## データについて

進捗・レポート・用語集はブラウザのLocalStorageへ保存される。更新前にJSONエクスポートを推奨する。
